# Chemistry Solver – Chemie Klasse 9

Eigenständige Website (eine einzige Datei: `index.html`, keine Installation, keine externen Abhängigkeiten).

## Lokal öffnen
`index.html` per Doppelklick im Browser öffnen.

## Auf GitHub Pages veröffentlichen
1. Auf github.com ein neues Repository anlegen (z. B. `chemistry-solver`, öffentlich).
2. „Add file → Upload files“: `index.html` und `README.md` hochladen, „Commit changes“.
3. Im Repository: **Settings → Pages**. Bei „Build and deployment“ als Quelle „Deploy from a branch“, Branch `main`, Ordner `/ (root)` wählen, speichern.
4. Nach etwa einer Minute ist die Seite erreichbar unter `https://DEIN-NAME.github.io/chemistry-solver/`.

Alternativen ohne GitHub: Netlify Drop (netlify.com/drop) oder Cloudflare Pages, einfach die Datei hineinziehen.

## Hinweise
- Alle Berechnungen laufen im Browser, es werden keine Daten gesendet.
- Foto-Texterkennung und KI-Anbindung sind nicht enthalten (siehe Chat).
